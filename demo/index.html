Bounding box around A

The smallest latitude/longitude box holding every point within the radius — a cheap prefilter before an exact distance check. Across the antimeridian its west edge is east of its east edge; around a pole it spans all longitudes.

Point C against the path from A to B

Cross-track: how far C is from the great circle through A and B, negative to the left looking from A. Along-track: how far from A the nearest point of that path lies, negative if behind A.

Longitude

The library has no dependencies and ships as an ES module with types; see the README for the full API. Distances use the IUGG mean radius, 6371.0088 km, on a sphere.
